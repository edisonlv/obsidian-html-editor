# Obsidian HTML Editor — 使用说明

本文档对应插件 **v1.8.2** 及相近版本，说明界面布局、预览交互、属性面板与原型布局等能力。

---

## 1. 能做什么

- 在 Obsidian 内打开并编辑库中的 `.html` / `.htm` 文件
- **四种视图**：预览、画布、源码、分栏
- 在预览里**点选元素**、查看类型与 DOM 路径，并**定位到源码**
- **改文字**：在预览中直接编辑可见文字（designMode）
- **布局 / 原型**：连点切层、拖动块、插入原型块、设置字色/底色
- 工具栏编辑：粗体、标题、链接、媒体、列表等
- 可选在预览中执行页面内 **JavaScript**（脚本开关）

---

## 2. 界面总览

```
┌─────────────────────────────────────────────────────────────┐
│ [预览|画布|源码|分栏] │ 选择|布局|改文字 │ 工具▾ 刷新 浏览器 JS │  ← 顶栏（默认一行）
├─────────────────────────────────────────────────────────────┤
│ （点击「工具 ▾」后展开：撤销、粗体、链接、H1… / 字色、插块…）   │  ← 可折叠，默认收起
├──────────────────┬──────────────────────────────────────────┤
│  源码编辑器       │  预览画布（iframe，占满剩余区域）          │
│  （分栏/源码时）  │  ┌──────────────────────┐                │
│                  │  │ 选中后出现 → 属性浮层 │                │
│                  │  └──────────────────────┘                │
└──────────────────┴──────────────────────────────────────────┘
```

设计原则：**画布优先**。工具和属性尽量不常驻占空间；需要时再展开。

---

## 3. 视图模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **预览** | 仅右侧预览，无源码栏 | 查看效果、点选元素 |
| **画布** | 全屏预览，不显示源码、不自动跳转代码 | 纯页面编辑 / 原型 |
| **源码** | 仅 CodeMirror 编辑器 | 改 HTML 结构、批量替换 |
| **分栏** | 左源码 + 右预览，可拖中间分割条 | 对照修改（推荐日常） |

切换方式：顶栏胶囊按钮，或命令面板 **Toggle view mode**。

---

## 4. 预览交互模式（互斥）

顶栏 **选择 | 布局 | 改文字** 三种模式**不能同时生效**，避免「一点就拖动」或「改字时点错层」。

### 4.1 选择

- **单击**预览中的元素 → 高亮选中，右上角弹出**属性浮层**
- **在同一位置连续点击** → 在重叠元素间切换层级（等同「下一层」）
- 悬停时显示浅色描边
- 分栏下可配合设置「点选后自动定位源码」

### 4.2 布局（原型）

在「选择」能力基础上增加：

- **拖动**块级元素移动位置（松开即写入预览 DOM，并同步回源码）
- **插入位置**：内 / 下 / 上（属性浮层内，仅布局模式且已选中时显示）
- **插块…**：打开块类型选择（按钮、卡片、栅格等原型 HTML）
- **字色 / 底色**：对选中元素或选区设色

流程建议：

1. 切换到 **布局**
2. 在预览中 **点击**目标元素（连点可选更外层/内层）
3. 在属性浮层选 **插入位置**（内/下/上）
4. 顶栏 **工具 ▾** → **插块…**，或先 **字色/底色**
5. 需要微调位置时 **拖动**元素
6. 点 **刷新** 后，新插入且带 `data-he-proto` 的块可再次被点选；未映射行号的块会显示「未映射」

### 4.3 改文字

- 预览进入 **designMode**，可直接改可见文字
- **不会**在普通单击时弹出属性浮层（避免与输入冲突）
- **Alt + 单击** 仍可选中元素并打开属性、定位源码（与设置「点选后自动定位源码」配合）

## 5. 属性浮层

**何时出现**

- 处于 **预览 / 画布 / 分栏**（有预览的一侧）
- 已在预览中 **选中元素**（选择/布局：单击；改文字：Alt+单击）

**未选中时**：不占宽度，画布全屏。

**内容**

| 区域 | 内容 |
|------|------|
| 类型徽章 | 按钮、文本、容器、图片等（根据标签与结构推断） |
| 标题 | 元素简短描述（标签 + 类名/文本摘要） |
| 元信息 | 源码行号、层级（画布模式无行号，仅层级） |
| DOM 路径 | 可滚动查看完整路径 |
| 操作 | 定位源码、父级、子级、下一层 |
| 插入位置 | 仅 **布局** 模式：内 / 下 / 上 + 一句说明 |

**关闭**：点浮层右上角 **×**，取消选中并清除预览内高亮。

**画布模式**：「定位源码」按钮隐藏（因不显示源码栏）。

## 6. 工具栏

### 6.1 顶栏（始终可见）

- **视图切换**：预览 / 画布 / 源码 / 分栏
- **交互模式**：选择 / 布局 / 改文字
- **工具 ▾ / 工具 ▴**：展开或收起下方工具条
- **刷新**：按当前源码重新生成预览 iframe
- **浏览器**：用系统默认浏览器打开当前 HTML 文件
- **JS / JS×**：是否允许执行 HTML 内 `<script>`（关闭时会剥离脚本再预览）
- **状态**：行数 · 字符数

### 6.2 工具条（展开后）

**内容编辑**（第一行）

- 历史：撤销、重做
- 文字：粗体、斜体、下划线、删除线、清格式
- 链接与媒体：链接、媒体、本文媒体
- 块级：H1–H3、段落、列表、引用、代码、换行、删块

**原型布局**（第二行）

- 字色、底色、插块…（需在 **布局** 模式且预览中已选中元素）

> 在 **源码** 侧编辑时，部分操作作用于 CodeMirror 光标处；在 **预览** 侧则作用于当前选中元素或 designMode 选区。

---

## 7. 分栏与调整比例

- **分栏** 模式下，拖动中间竖条可改变源码/预览宽度
- 预览侧修改会通过消息同步写回左侧源码（含布局拖动、改文字、插块等）

## 8. 插件设置

路径：**Obsidian 设置 → HTML Editor**

| 设置项 | 说明 |
|--------|------|
| Default view mode | 打开 HTML 文件时的默认视图（含画布） |
| Allow scripts | 预览是否执行 JS；关闭则剥离 `<script>` |
| Font size / Word wrap / Line numbers | 源码编辑器外观 |
| Default preview interaction | 默认：选择 / 布局 / 改文字 |
| Auto locate in source | 分栏下点选（或改文字 Alt+点选）后自动选中左侧对应标签 |
| Auto refresh | 改源码后是否自动刷新预览 |
| Refresh delay | 自动刷新延迟（毫秒） |

---

## 9. 命令面板

在 HTML 编辑器视图为焦点时可用：

| 命令 | 作用 |
|------|------|
| Toggle view mode | 循环：预览 → 画布 → 源码 → 分栏 |
| Refresh HTML preview | 手动刷新预览 |
| HTML Editor: Undo / Redo | 撤销 / 重做（预览改字或工具操作后） |
| Toggle JavaScript execution in preview | 切换脚本开关 |

源码编辑器内：**Ctrl/Cmd + S** 保存（与 Obsidian 一致）。

## 10. 常见问题

### 属性浮层一直不出现？

1. 确认不是纯 **源码** 模式（需要预览/画布/分栏）
2. **改文字** 模式下请用 **Alt + 单击**，普通单击用于输入文字
3. 确认点击在 **iframe 预览内容** 上，而非空白边距
4. 插块后若无法点选，先点 **刷新** 再试

### 插块 / 字色提示「请切换到布局模式」？

顶栏选 **布局**，并在预览中 **先选中**一个元素。

### 预览和源码不一致？

- 点 **刷新** 强制从源码重建 iframe
- 布局模式下在预览中的修改会写回文件；若未保存，切换文件前请 **保存**

### 脚本不运行？

顶栏 **JS** 需为 ON，且设置里 **Allow scripts** 开启。部分沙箱限制仍可能阻止个别脚本。

### 画布模式想看代码？

切换到 **分栏** 或 **源码**；画布故意隐藏源码以扩大编辑区域。

## 11. 安装与更新

**手动安装**：将 `main.js`、`manifest.json` 放入：

```text
<你的库>/.obsidian/plugins/obsidian-html-editor/
```

在 **设置 → 社区插件** 中启用 HTML Editor。

**开发构建**：

```bash
npm install
npm run build
```

修改代码后需重新构建并复制到插件目录，然后在 Obsidian 中 **重载插件** 或重启。
